# Восемь недель с криптой — сайт

Статический сайт без сборки. Открывается как есть, деплоится копированием папки.

```
site/
├── index.html
└── assets/
    ├── css/
    │   ├── tokens.css      дизайн-токены (цвет, типографика, сетка, ритм, радиусы, motion)
    │   ├── styles.css      примитивы и компоненты
    │   └── responsive.css  брейкпоинты, print, coarse pointer
    └── js/
        └── main.js         вся интерактивность
```

## Что нужно настроить перед запуском

**1. Ссылка на запись** — одна строка в начале `assets/js/main.js`:

```js
var CTA_URL = '#call';
```

Замените на ссылку Telegram или Calendly — она подставится во все кнопки на странице
(шапка, герой, мобильное меню, финальный CTA, липкая кнопка, подвал). Внешние ссылки
автоматически получают `target="_blank"` и `rel="noopener"`.

**2. Логотипы клиентов** — в секции «Кто ведёт» четыре пунктирных плейсхолдера
`.logostrip__slot`. Замените каждый на `<img>` с реальным логотипом. Плейсхолдеры
намеренно выглядят как плейсхолдеры — выдуманных логотипов в вёрстке нет.

**3. Оферта.** Дисклеймер в конце секции «Границы» и в подвале — это не оферта.
Договор нужно готовить отдельно с юристом под выбранную юрисдикцию.

## A/B первого экрана

Три варианта заголовка, по умолчанию B.

| URL | Вариант |
|---|---|
| `/` или `/?v=b` | **Control** — «Криптой гораздо спокойнее пользоваться…» |
| `/?v=a` | **Fear** — «Ваши деньги уже в крипте…» |
| `/?v=c` | **Product** — «Научитесь самостоятельно хранить…» |

`/?ab=1` показывает переключатель в левом нижнем углу, чтобы сравнить варианты вживую.

## Локальный запуск

```bash
python3 -m http.server 4173 --directory site
```

Затем откройте `http://localhost:4173`. Сервер нужен только потому, что CSS и JS
подключены относительными путями — открытие `index.html` двойным кликом тоже работает
в большинстве браузеров.

## Деплой

Любой статический хостинг: Netlify, Vercel, Cloudflare Pages, GitHub Pages, S3, nginx.
Загрузите содержимое папки `site/` — сборка не требуется. Единственная внешняя
зависимость — Google Fonts.

## Дизайн-система

Тёплая слоновая бумага против холодного кобальта: тёплые нейтрали — знакомый мир,
единственный холодный акцент — новая система. Все значения живут в `tokens.css`,
магических чисел в компонентах нет.

- **Шрифты.** Onest — заголовки; Golos Text — текст и интерфейс; IBM Plex Mono — данные
  (суммы, сети, адреса, метки). У всех трёх полная кириллица.
- **Радиусы.** 4px для редакционного контента, 20–28px для продуктовых визуалов,
  pill для кнопок и чипов.
- **Сетка.** 12 колонок, гаттер 16→32px, паддинг страницы 18→80px, контент максимум 1440px.
- **Ритм.** Секции 72→176px, кинематографичные 96→240px. Высоты секций намеренно разные.
- **Тёмная тема.** Полноценная, на уровне токенов, во всех трёх состояниях
  (`prefers-color-scheme`, явный `data-theme="light"`, явный `data-theme="dark"`).

## Доступность и поведение

- Семантическая разметка, skip-link, видимый фокус, `aria-expanded` на аккордеоне и меню.
- `prefers-reduced-motion` отключает все анимации, контент показывается сразу.
- Без JS: весь контент читается, карта экосистемы остаётся сгруппированным списком.
- Есть print-стили.

## Проверенные разрешения

1920 · 1440 · 1366 · 1280 · 1180 · 1040 · 900 · 768 · 600 · 430 · 390 · 375,
плюс альбомная ориентация на низких экранах. Горизонтального скролла нет нигде,
тач-таргеты от 40px, минимальный размер основного текста — 17px.
